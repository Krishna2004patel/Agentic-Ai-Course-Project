KLE Technological University
The grant assistant follows a goal → plan → act → observe loop and routes questions to the relevant grant, file or research-search tool.
Reusable functions handle grant lookup, eligibility information and research-paper search; project memory can retain relevant facts for later retrieval.
The MCP-style connector brings together three tools: SQLite grant database, permitted README file reader and the external OpenAlex API.
The current worklet runs as a Python command-line program and invokes tools when requested; scheduled runs and detailed audit tracing are not implemented.
The current workflow routes each question to the matching tool in sequence. Parallel agent swarms and a full node-graph workflow are future extensions.
OpenAlex searches research papers by topic and returns metadata such as titles, authors, years and links to support research discovery.
Safety is supported by a restricted local README reader and read-only database queries. Cloud deployment, CI evaluation and rollback controls are not yet implemented.
